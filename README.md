# PA1 - Desarrollo de Videojuego 2D

Proyecto desarrollado en Unity para el Producto Académico N.° 1 del curso Desarrollo de Videojuegos.

El proyecto consiste en un videojuego de plataformas 2D desarrollado en Unity.

Actualmente incluye:

- Escenario 2D con Tilemap.
- Personaje principal.
- Movimiento horizontal.
- Orientación del personaje.
- Rigidbody2D y Collider2D.
- Colisiones con el escenario.
- Fondo y plataformas.

## Tecnologías utilizadas

- Unity 6
- C#
- Git
- GitHub
